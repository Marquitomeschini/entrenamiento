CSS: `#t-next{color:var(--mut);margin:0;min-height:1.4em}`, `#timer.reps b{font-size:64px}`.
- [ ] `timer.js`: estado `steps, i, finAt, tick`. `run(steps)`: `i = 0; show()`. `show()`: paso actual; si `seg` → `finAt`, tick 250 ms, al llegar a 0 → beep → `next()`; si `reps` → texto `${reps} reps`, sin tick, botón "Hecho". `#t-next` = siguiente paso o "Último". `next()`: `i++`; si `i === steps.length` → estado `done` (rojo si era descanso simple; texto "Listo"), sino `show()`. Descanso simple: `start(seg) = run([{ tipo: 'desc', seg, nombre: 'Descanso' }])`, y al terminar queda en rojo con "Listo" (igual que hoy). `#timer-skip` → `next()`, visible solo si `steps.length > 1`. `close()` limpia. Expone `{ start, run, close, activo: () => !el.hidden }`.
